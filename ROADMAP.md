# Roadmap

## P0 — Playback reliability

- Make requested and effective playback speed remain identical on current YouTube.
- Harden behavior when YouTube internally resets `playbackRate`.
- Validate player replacement and SPA navigation behavior in Chrome, Edge, and Brave.
- Add diagnostics that distinguish requested speed from effective player speed.

## P1 — User experience

- Better recovery messaging when the player is unavailable.
- Optional keyboard shortcut customization.
- Preset customization.
- Cleaner high-speed audio behavior guidance.

## P2 — Release quality

- Broader browser regression matrix.
- Packaged release ZIP generated by CI.
- Chrome Web Store readiness checklist.
- Store screenshots and promotional assets.
- Optional Firefox compatibility investigation.

The roadmap is intentionally reliability-first. New features should not come at the cost of deterministic playback control.

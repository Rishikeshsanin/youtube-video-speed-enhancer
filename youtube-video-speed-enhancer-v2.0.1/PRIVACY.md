# Privacy Policy

**YouTube Video Speed Enhancer** is designed to work entirely inside the browser.

## Data collection

The extension does **not** collect, sell, transmit, or share personal information, browsing history, YouTube watch history, video titles, account information, analytics, telemetry, or advertising identifiers.

## Stored settings

The extension stores only these preferences through Chrome's extension storage API:

- selected playback speed,
- keyboard speed increment,
- whether the on-screen speed indicator is enabled.

Chrome may sync these preferences between browsers when Chrome Sync is enabled for the user's profile.

## Network access

The extension does not make its own external network requests. It runs only on matching YouTube pages so it can control the HTML video player.

## Changes

If the extension's data practices change in a future release, this document should be updated before that release is published.
